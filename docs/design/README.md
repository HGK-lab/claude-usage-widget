## v2 구조 요점

- 세션은 1시간 칸 5개, 주간은 리셋 요일부터 7칸. 칸은 **시간 축**: 지난 시간만큼 칠하고 현재 칸에 테두리.
- 사용량은 칸 위에 겹친 얇은 막대. 막대 끝이 칠한 칸보다 앞서면 빨리 쓰는 중.
- 70% 이상 앰버 + "70% 넘음" 라벨, 90% 이상 또는 예약선 침범은 딥 레드브라운. 카드 구조는 상태와 무관하게 같다.
- 추가 기능 후보: 주간 하루 예산, 분 단위 리셋 카운트다운, 오류 시 마지막 값 흐림 + 경과 시간, 설정 패널.

## 원래 팔레트에서 바꾼 것 (brand)

- % 숫자는 잉크 고정. 앰버·레드브라운 글자는 테라코타 위에서 안 읽혀 막대와 라벨에만 쓴다.
- 보조 글자 `#7b4432` → `#57291b` (대비 보강).
